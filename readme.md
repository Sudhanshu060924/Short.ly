# 🔗 URL Shortener API

A full-stack URL Shortener built with FastAPI, PostgreSQL, React, and SQLAlchemy.

## Features

- Shorten URLs
- Redirect URLs
- Click Analytics
- PostgreSQL Database
- React Frontend

## Tech Stack

- FastAPI
- SQLAlchemy
- PostgreSQL
- React
- Axios

## Run Backend

```bash
pip install -r requirements.txt
uvicorn app.main:app --reload
```

## Run Frontend

```bash
npm install
npm run dev
```
